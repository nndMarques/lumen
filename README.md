# Lumen

Exame de consciência e Santo Terço, na palma da mão.

- **Confissão:** quatro exames escritos a partir do Catecismo (Dez Mandamentos com filtro por estado de vida, pecados capitais, exame breve e para crianças), uma lista privada para levar à confissão, o passo a passo e o ato de contrição. O botão "Confessei" apaga a lista.
- **Terço:** guiado conta por conta, com os mistérios do dia, em português ou em latim.
- **Privacidade:** sem conta, sem servidor. Tudo fica guardado só no aparelho (localStorage).
- Funciona offline e pode ser instalado na tela de início do celular.

## Rodar no computador

```bash
python -m http.server 5180
```

Depois abra http://localhost:5180.

Feito com HTML, CSS e JavaScript puros, sem etapa de build.
